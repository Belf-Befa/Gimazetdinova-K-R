## Запуск клиента (Vue 3)

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно http://localhost:5173

## Запуск сервера (C# ASP.NET Core)

```bash
cd backend
dotnet restore
dotnet run
```

API: http://localhost:5000  
Swagger: http://localhost:5000/swagger  
Health: http://localhost:5000/health
